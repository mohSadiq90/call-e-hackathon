## Getting Started

### Clone the Repository
```bash
git clone https://github.com/mohSadiq90/call-e-hackathon.git
cd call-e-hackathon
```

### Development Guidelines
- Maintain all build caches and heavy temporary files outside the home workspace (e.g. in `/tmp`) to respect local disk limits.
- Keep `PROGRESS.md` updated with daily logs, architecture decisions, and task status.
- Ensure work is committed and pushed cleanly to `main`.
